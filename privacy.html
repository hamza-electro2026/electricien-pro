Politique de confidentialité

Dernière mise à jour : 8 novembre 2026.

1. Données saisies dans les calculateurs

Dans la version actuelle, les valeurs que vous saisissez dans les calculateurs sont traitées dans votre navigateur pour afficher les résultats. Le code de l’application ne prévoit pas de compte utilisateur, de formulaire d’inscription ni d’envoi de ces valeurs à un serveur applicatif.

2. Stockage hors ligne

L’application utilise un service worker pour mettre en cache certains fichiers nécessaires à son fonctionnement hors ligne. Les données de calcul saisies ne sont pas enregistrées par une fonction de sauvegarde de l’application. Le cache peut être supprimé depuis les paramètres du navigateur.

3. Hébergement

Le site est actuellement hébergé par GitHub Pages. Comme pour tout service d’hébergement, le fournisseur peut traiter des données techniques de connexion et des journaux selon ses propres règles. Consultez la déclaration de confidentialité de GitHub.

4. Publicité et mesure d’audience

À la date indiquée ci-dessus, l’application ne contient pas de code publicitaire ni d’outil d’analyse d’audience intégré. Si ces services sont ajoutés ultérieurement, cette politique sera mise à jour avant leur activation afin d’expliquer les données et les choix disponibles.

5. Liens externes et enfants

Les liens vers des services tiers sont soumis aux politiques de leurs éditeurs. L’application est un outil technique général et ne demande pas volontairement de données personnelles.

6. Contact

Pour une question concernant cette politique, utilisez la page Contact.

سياسة الخصوصية

آخر تحديث: 8 نونبر 2026.

1. المعلومات المدخلة في الحسابات

في النسخة الحالية، الأرقام التي تدخلها في أدوات الحساب تتم معالجتها داخل المتصفح لإظهار النتائج. التطبيق لا يتضمن حالياً حساب مستخدم أو استمارة تسجيل أو إرسال قيم الحساب إلى خادم خاص بالتطبيق.

2. العمل دون إنترنت

يستعمل التطبيق Service Worker لحفظ بعض الملفات الضرورية مؤقتاً حتى يعمل دون إنترنت. التطبيق لا يتضمن وظيفة لحفظ أرقام الحساب التي تدخلها. يمكن حذف الملفات المخزنة من إعدادات المتصفح.

3. الاستضافة

الموقع مستضاف حالياً عبر GitHub Pages. قد يعالج مزود الاستضافة بيانات تقنية وسجلات الاتصال وفق سياسته. راجع سياسة الخصوصية ديال GitHub.

4. الإعلانات وقياس الزيارات

في تاريخ التحديث أعلاه، لا يتضمن التطبيق كود إعلانات أو أداة مدمجة لقياس الزيارات. إذا أضيفت هذه الخدمات مستقبلاً، سيتم تحديث هذه السياسة قبل تفعيلها لشرح البيانات والاختيارات المتاحة.

5. التواصل

لأي سؤال حول الخصوصية، استعمل صفحة التواصل.
