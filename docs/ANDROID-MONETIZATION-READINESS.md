# Electricien Pro — préparation Android et monétisation

## État vérifié sur `main` (16 novembre 2026)

- L'application actuelle est une PWA hébergée sur GitHub Pages.
- Le manifeste contient déjà le nom, نقطة الانطلاق، نطاق التطبيق، وأيقونات 192/512.
- لا توجد حالياً حزمة Android أصلية أو تكامل Google Mobile Ads SDK أو Google Play Billing في `index.html`.
- سياسة الخصوصية الحالية تصرّح بشكل صحيح بأن الإعلانات غير مفعّلة.
- لا توجد طلبات دمج مفتوحة وقت الفحص.

## قرار التنفيذ

لن نضع معرفات إعلانية وهمية، ولن نعرض إعلانات تجريبية للمستخدمين، ولن ننشئ زر شراء يوهم بأن الأداء يعمل. لا يمكن تفعيل AdMob أو Billing فعلياً قبل إنشاء تطبيق Android بمعرّف نهائي وربطه بحسابات المالك.

## الترتيب الآمن

1. تثبيت معرّف الحزمة النهائي (اقتراح يحتاج تأكيداً وتحققاً من التوفر: `com.hamzaelectro.electricienpro`). لا تغيّره بعد النشر.
2. إنشاء Android Trusted Web Activity (TWA) من PWA، ثم توليد ملف AAB موقّع وإعداد Digital Asset Links (`/.well-known/assetlinks.json`) ببصمة شهادة التوقيع الصحيحة.
3. اختبار التثبيت، فتح الروابط، العمل دون اتصال، الرجوع، اللغة العربية/الفرنسية، وحجم الشاشات على Android.
4. بعد إنشاء تطبيق Play Console: إعداد AdMob بمعرّف التطبيق ووحدات إعلان حقيقية، دمج Google Mobile Ads SDK داخل غلاف Android، مع إبقاء الإعلان بعيداً عن نتائج الحساب والأزرار الحساسة.
5. إعداد Google Play Billing لميزة Premium/إزالة الإعلانات أو المنتجات الرقمية داخل التطبيق. لا نستخدم أداءً خارجياً لفتح مزايا رقمية في تطبيق Play.
6. تحديث سياسة الخصوصية ونموذج Data safety والتصريح بوجود الإعلانات، ثم اختبار الإعلانات عبر test ad units قبل الإنتاج.
7. لا يتم الدمج إلى `main` ولا النشر حتى تنجح الاختبارات ومراجعة المالك.

## ما يتطلب حساب المالك أو موافقته

- تأكيد Package ID النهائي واسم التطبيق.
- حساب Play Console والتحقق من الهوية ورسوم التسجيل.
- حساب AdMob وإعداد الدفع والتحقق، ثم إنشاء App ID وAd Unit IDs.
- بيانات توقيع Android/AAB وحفظ مفتاح التوقيع بأمان.
- إعداد منتجات Billing وأسعارها وبلدان التوزيع.

**تنبيه:** رسوم التسجيل أو إضافة الإعلانات لا تضمن أي دخل. الأرباح تعتمد على قبول التطبيق، أهلية الحساب، عدد المستخدمين، الزيارات، ومعدلات التحويل والإعلانات.
